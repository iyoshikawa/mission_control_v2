Status: active
Last updated: 2026-03-13 09:00 America/Los_Angeles

## 1) External build style for Mission Control
- **decision:** what implementation style should external coders use for the first pass?
- **why it matters:** a heavy app stack too early creates maintenance drag and slows iteration before the information model is proven.
- **options:** static HTML/CSS/JS; lightweight app framework; heavier application stack
- **recommendation:** static-first or very lightweight framework only
- **urgency / deadline:** soon

## 2) First real data sections to prioritize
- **decision:** which sections should get real operating data first?
- **why it matters:** attempting to fully populate everything at once will create noise and low-value busywork.
- **options:** priorities + decision queue; ops health; cost watch; all at once
- **recommendation:** priorities + decision queue first, then ops health, then cost watch
- **urgency / deadline:** soon
